
# Restaurant-website-project
### CONTRIBUTING Guidelines  
Welcome collaborators! Please follow these rules:  
1. Always pull the latest changes before starting work. 
2. Work on your own branch (do not edit main directly).
3. Commit messages should be clear and descriptive.
4. Push only tested code.
5. Respect others' work and review pull requests carefully.  Thank you!

# Setup Guide

1. Clone the repo
2. Copy .env.example to .env
3. Setup database in phpMyAdmin
4. Import database/restaurant.sql
5. Run project in localhost
